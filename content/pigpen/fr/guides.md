# Guides pas à pas

## Chiffrer votre premier message

1. Tapez votre message dans {{control:message-input}}.
2. Choisissez un jeu de symboles avec {{control:variant-selector}} —
   les grilles maçonnes classiques par défaut. Les variantes codent le
   même chiffre ; elles ne diffèrent que par l'agencement et le
   pointage des cases.
3. Regardez le bandeau de glyphes se remplir sous le sélecteur : chaque
   lettre tapée devient un dessin. Le champ {{control:output}} affiche
   la légende « copier comme texte » — la liste des glyphes est un
   graphique, la légende est donc ce qu'un presse-papiers peut porter.

## Déchiffrer un message reçu

1. Appuyez sur le bouton d'échange {{control:swap}} pour passer en mode
   déchiffrement.
2. Le clavier de glyphes remplace le bandeau : cliquez les symboles du
   message dans l'ordre — les touches ne montrent que les dessins, sans
   lettres, exactement comme un vrai cryptogramme. Chaque clic ajoute
   sa lettre au message.
3. Vous pouvez aussi taper directement dans {{control:message-input}}
   si un clavier vous est plus pratique ; les deux chemins nourrissent
   le même message.
4. Lisez le texte déchiffré dans {{control:output}}.

## Lire le pigpen autour de vous

Dès qu'on connaît les trois formes, le pigpen apparaît partout :

1. Pierres tombales et plaques commémoratives — les francs-maçons
   l'employaient dans les gravures, et un célèbre cryptogramme sur une
   tombe new-yorkaise se lit « Remember death ».
2. Chasses au trésor, escape games et livres pour enfants — le pigpen
   est l'« écriture secrète » la plus empruntée de la presse, la plupart
   des auteurs d'énigmes supposent que vous savez la lire.
3. Fiction et jeux — des histoires de trésor pirate aux jeux vidéo,
   les fragments de grille signifient « message secret » à tout
   lecteur.
