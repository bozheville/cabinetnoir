# Step-by-step guides

## Encrypt your first message

1. Type your message into {{control:message-input}}.
2. Pick a symbol set with {{control:variant-selector}} — the classic
   masonic grids are the default. The variants all encode the same
   cipher; they only differ in how the pens are arranged and dotted.
3. Watch the glyph strip fill up under the selector: every letter you
   type becomes a drawing. The {{control:output}} field shows the
   copy-as-text legend — the glyph list is graphics, so the legend is
   what a clipboard can carry.

## Decrypt a message you received

1. Press the swap button {{control:swap}} to switch to decrypt mode.
2. The glyph keyboard appears instead of the strip: click the symbols
   of the message in order — the keys show only the drawings, no
   letters, exactly like a real ciphertext. Each click appends its
   letter to the input.
3. You can also type into {{control:message-input}} directly if a
   keyboard is easier for you; both paths feed the same message.
4. Read the decoded text in {{control:output}}.

## Read pigpen around you

Once you know the three shapes, pigpen starts appearing in the wild:

1. Gravestones and memorial plaques — Freemasons used it in
   engravings, and a famous cipher on a New York tombstone reads
   "Remember death".
2. Puzzle hunts, escape rooms and children's books — pigpen is the
   most borrowed "secret writing" in print, so most puzzle authors
   assume you can read it.
3. Fiction and games — from pirate-treasure stories to video games,
   the grid fragments signal "secret message" to any reader.
