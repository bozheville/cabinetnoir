# Guides pas à pas

## Encodez votre premier message

1. Tapez votre message dans {{control:message-input}}. Les lettres
   deviennent des motifs point-trait séparés par des espaces ; une
   espace entre mots devient une barre oblique.
2. Si vous préférez un autre aspect, choisissez les caractères qui
   jouent le point {{control:dot-symbol}} et le trait
   {{control:dash-symbol}} — les motifs ne changent pas.
3. Lisez la ligne encodée dans {{control:output}}. Notez que les
   caractères inconnus (ponctuation, accents) sont supprimés — le fil
   n'en avait pas l'usage non plus.

## Décodez un message reçu

1. Collez le Morse dans {{control:message-input}} et appuyez sur le
   bouton d'échange {{control:swap}}.
2. Conservez le format de l'expéditeur : une espace entre les
   lettres, une barre oblique entre les mots. Tous les caractères
   courants de point et de trait sont acceptés et normalisés.
3. Lisez le texte décodé dans {{control:output}}. Si une lettre sort
   mal, cherchez une espace manquante ou doublée — c'est l'espacement
   qui piège le Morse tapé à la main.

## Lire le rythme à l'oreille (bonus)

1. Comparez les motifs de l'exemple : E vaut une unité, T en vaut
   trois. Les motifs les plus courts appartiennent aux lettres les
   plus courantes.
2. À l'écoute d'un vrai Morse, ce sont les *pauses* qui définissent
   les lettres — une suite ininterrompue de signal ne veut rien dire
   seule.
3. Voilà pourquoi les opérateurs prononcent « dits » et « dahs » avec
   le rythme dans la voix : le code a été conçu pour l'oreille, pas
   pour l'œil.
